# Suggested cybersecurity knowledge sources

Use official, trusted material and download the public PDF versions where available. The application indexes PDFs placed in `data/raw/`.

1. **CISA — Secure Our World**: https://www.cisa.gov/secure-our-world
   - Practical guidance on strong passwords, multifactor authentication, software updates and phishing awareness.
2. **NIST — Cybersecurity Framework 2.0**: https://www.nist.gov/cyberframework
   - A framework for managing and reducing cybersecurity risk.
3. **OWASP Top 10**: https://owasp.org/www-project-top-ten/
   - Awareness of common web application security risks and defensive mitigations.
4. **MITRE ATT&CK**: https://attack.mitre.org/
   - A knowledge base of adversary tactics and techniques, useful for defensive threat understanding.
5. **CERT-In**: https://www.cert-in.org.in/
   - Indian cybersecurity advisories and incident-related guidance. Check the site for current publications and advisories.

## Suggested initial PDF collection

For a balanced student project, begin with 3–5 documents: one cybersecurity awareness guide, one phishing guidance document, the NIST CSF 2.0 publication, an OWASP Top 10 document, and a relevant CERT-In advisory. Prefer searchable PDFs with selectable text. Record each document's title, publisher and retrieval date in your project report.

Do not treat the knowledge base as a live threat-intelligence feed. Documents must be refreshed manually, and chatbot answers are limited to the indexed material.
